# Centelha — Brand Package v1.0

Pacote produzido a partir das três referências fornecidas em 05/10/2026. A marca não foi redesenhada: a geometria foi reconstruída em vetor e sistematizada.

## Comece aqui
- `centelha-brand-guide.html` — guia completo em uma página, com alternância claro/escuro.
- `assets/logo/` — símbolos, assinaturas horizontais e empilhadas, coloridas e monocromáticas.
- `assets/app/` — app icon master, preview arredondado, Android adaptive, Android 13+ monochrome, Jovem/Kids, favicon e splash.
- `assets/icons/` — 12 ícones de interface SVG.
- `assets/patterns/` — padrões repetíveis claro/escuro.
- `assets/mockups/` — início, player e leitura acompanhada em light/dark.
- `assets/social/` — templates de compartilhamento e redes sociais.
- `tokens/tokens.css` — variáveis CSS e suporte a `prefers-color-scheme`.
- `tokens/tokens.json` — design tokens para integração multiplataforma.
- `tokens/centelha_theme.dart` — exemplo inicial de ThemeData Flutter.
- `reference/` — imagens raster originais usadas como referência.

## Uso rápido
Para tamanhos abaixo de 48 px, prefira `symbol-flat.svg` sem glow. Para a App Store e Google Play, use o master full-bleed; o sistema operacional aplica a máscara do ícone. No Android, mantenha o foreground dentro da zona segura do adaptive icon.

## Tipografia
Recomendadas: **Comfortaa** (títulos; Google Fonts) e **Atkinson Hyperlegible** (texto/leitura; Google Fonts). O wordmark oficial está vetorizado — não deve ser recomposto digitando a palavra.

## Observação de produção
A geometria vetorial é uma reconstrução limpa das referências raster. Antes de registro de marca e publicação definitiva, faça a validação visual final e busca de anterioridade/colisão de marca.
